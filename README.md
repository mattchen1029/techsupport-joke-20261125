# Have You Tried Turning It Off?

An entry for make.fun's **Have You Tried Turning It Off?** bounty
(`u-motasimfuad-have-you-tried-turning-it-off-154a938b`).

desperate customer — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR`).

> Let's turn it off and on again — and if that doesn't work, I'll stay on the line so we can be disappointed together.
